BCC SAFE GUARD — учебный демонстрационный прототип.
Загрузка: разместите содержимое архива на HTTPS-хостинге (например, Netlify).
Функции: ручной анализ текста/описания звонка, эвристическая оценка риска, тестовая проверка переводов, локальный журнал.
Ограничения: не подключён к банку; не читает SMS и не прослушивает звонки; не блокирует реальные карты/переводы; не является официальным приложением Bank CenterCredit.
Используйте только вымышленные тестовые данные. Для реальной интеграции необходимы разрешения ОС, серверная инфраструктура, аудит безопасности и официальный банковский API/договор.
